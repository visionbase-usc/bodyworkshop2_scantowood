# mesh2wood

丟一個 mesh 進來，算出可以用 CNC 切的木構：DXF 切割檔、3D 檢視、組裝順序。

メッシュを入れると、CNC で切れる木の構造体を計算する。DXF、3D ビューア、組み立て順を出力。

## 怎麼用 / 使い方

1. 打開網頁：**https://visionbase-usc.github.io/bodyworkshop2_scantowood/**
2. 確認左邊的板厚、刀徑、板材是你們實際用的。
3. 把 mesh 拖進視窗，等它算完。
4. 看 3D，滿意就下載 DXF。

1. Web ページを開く。
2. 左の板厚・刃物径・板のサイズを実際の値にする。
3. メッシュをウィンドウにドラッグする。
4. 3D を確認し、DXF をダウンロードする。

不用安裝，Windows、Mac 都能用，也不需要顯卡。檔案不會上傳，全部在你的電腦上計算。

インストール不要。Windows でも Mac でも使える。ファイルはアップロードされず、すべて自分のパソコンで計算する。

支援 `.stl` `.obj` `.ply` `.glb`。mesh 有破洞也可以，例如掃描底部沒有封起來。3DGS 的 `.ply` 只有點，要先轉成 mesh。

- **第一次打開**要下載約 50 MB，之後瀏覽器會記住。全班同時用時，請提早打開。
- **計算時間**：78 萬面約 25 秒，104 MB 的 OBJ 約 2 分鐘（桌機實測，筆電會慢一些）。
- **要用電腦開**。手機記憶體不夠。

## 指令版 / コマンド版

沒有網路，或 mesh 大到瀏覽器跑不動時用。需要先裝 [Python](https://www.python.org/downloads/)（3.10 以上）。

ネットワークがないとき、またはブラウザで計算できないほど大きいメッシュに使う。

**Windows**：把 mesh 檔拖到 `DROP_MESH_HERE.bat` 上。第一次會自動安裝套件，約 2 分鐘。

**Mac**：雙擊 `run_mac.command`，把 mesh 拖進視窗，按 Enter。

```bash
pip install -r requirements.txt
python mesh2wood.py 我的模型.stl
python mesh2wood.py 我的模型.stl --size 800
```

## 輸出 / 出力

網頁版下載成一個 zip。指令版放在 mesh 旁邊的 `<檔名>_wood` 資料夾。/ Web 版は zip でダウンロード。コマンド版はメッシュの隣の `<ファイル名>_wood` フォルダに出力。

| 檔案 | 內容 |
|---|---|
| `sheet_01.dxf`… | 切割檔，一張板材一個檔，單位 mm，比例 1:1 / カットデータ |
| `viewer.html` | 3D 檢視，看到的就是切出來的樣子 / 3D ビューア |
| `sheets.png` | 排版預覽 / 板取りのプレビュー |
| `report.md` | 組裝順序、卡榫、要注意的地方 / 組み立て順など |
| `settings_used.json` | 這次用的參數 / 今回の設定 |

DXF 圖層 / レイヤー：

| 圖層 | 內容 |
|---|---|
| `CUT_OUTER` | 零件外框，含卡榫的槽 / 外形（溝を含む） |
| `CUT_INNER` | 內孔 / 内側の穴 |
| `LABEL` | 零件編號 / 部品番号 |
| `SHEET` | 板材邊界，不要切 / 板の外周（切らない） |

## 設定 / 設定

網頁左邊可以直接改，瀏覽器會記住。下表是全部參數，預設值在 `settings.json`，網頁也讀這個檔。**先改成你們實際的材料和刀具。**

Web ページの左で変更でき、ブラウザが覚える。初期値は `settings.json` にある。**まず実際の材料と刃物に合わせること。**

| 項目 | 預設 | 意思 |
|---|---|---|
| `size_mm` | 1000 | 作品最長邊 / 作品の一番長い辺 |
| `up_axis` | `auto` | 哪個軸朝上，`x` `y` `z`，可加負號（`-y`）。`auto`：OBJ、GLB 用 y，STL、PLY 用 z / 上向きの軸 |
| `thickness_mm` | 18 | 板厚 / 板厚 |
| `tool_diameter_mm` | 6 | 刀徑 / 刃物径 |
| `tolerance_mm` | 0.3 | 卡榫公差，要用實際板材試切 / 公差。実際の板で試し切りする |
| `sheet_mm` | 2440, 1220 | 板材尺寸 / 板のサイズ |
| `sheet_margin_mm` | 20 | 板材留邊 / 板の余白 |
| `part_gap_mm` | 12 | 零件間距 / 部品の間隔 |
| `abstraction` | 0.05 | 抽象程度。0 貼著原物，0.2 接近一整塊 / 抽象度 |
| `panel_spacing` | 0.14 | 板的疏密，越小板越多 / 板の密度。小さいほど多い |
| `coverage` | 0.85 | 要涵蓋多少體積才停 / どこまで体積を覆うか |
| `max_panels` | 16 | 木板數量上限 / 板の最大枚数 |
| `max_tilt_deg` | 0 | 板可以傾斜幾度。**0 以外可能插不進去** / 板の傾き。**0 以外は入らないことがある** |
| `holes` | true | 要不要開洞 / 穴を開けるか |
| `hole_size` | 0.42 | 洞的大小 / 穴の大きさ |
| `label_height_mm` | 12 | 編號字高 / 番号の文字高 |

同樣的 mesh 和設定，在同一個版本重算，結果相同。網頁版和指令版用的套件版本不同，算出來可能不完全一樣，遇到對稱的形狀還可能選到不同的板，兩邊都做得出來，但切割時請用同一邊的檔案。

同じメッシュと設定なら、同じ版では同じ結果になる。Web 版とコマンド版はパッケージの版が違うので、結果が少し変わることがある。切るときはどちらか一方のファイルにそろえること。

## 它怎麼算 / 仕組み

1. 把 mesh 變成實心的體積，`abstraction` 決定要多接近原物。
2. 每次挑一個能涵蓋最多體積的垂直剖面，當成一片板，每片都要和已選的板相交。
3. 決定組裝順序：後放的板從上面插下來。卡榫的槽方向由這個順序決定，所以一定插得進去。
4. 斜交的槽依夾角加寬，內角做狗骨頭。
5. 避開槽和孔開洞、排版、輸出。

## 檢查 / 検証

```bash
pip install manifold3d
python tests/verify.py 我的模型.stl
```

把切好的零件在 3D 裡組起來，檢查板和板不穿插、每片都插得進去，再把 DXF 讀回來檢查。結果會覆寫 `<檔名>_wood`，要留舊結果就加 `--out`。

切った部品を 3D で組み立てて検証する。`manifold3d` が必要。

## 限制 / 限界

- 目前只在電腦上驗證過，**還沒有實際切過**。第一次請先用紙板或小比例試切。
- 只確認幾何上組得起來，不算結構強度。「站得穩」是用重心估算的。
- `report.md` 的「要注意」要看。被槽切成兩塊的板、沒接到主體的零件都會列在那裡。
- 結果不像原物時，先看物體是不是躺著：`report.md` 和視窗都會顯示哪個軸朝上。

- コンピュータ上の検証のみで、**実際にはまだ切っていない**。最初は段ボールや縮小で試すこと。
- 幾何的に組めることだけを確認している。構造強度は計算していない。

## 部署 / デプロイ

GitHub repo 的 Settings → Pages，Source 選 `Deploy from a branch`，Branch 選 `main`、`/ (root)`，存檔後約 1 分鐘上線。不需要編譯。

`.nojekyll` 不能刪，否則 GitHub Pages 會略過 `m2w/__init__.py`。

本機測試不能雙擊 `index.html`，要開一個伺服器：

```bash
python -m http.server 8000
```

瀏覽器的 Python 由 [Pyodide](https://pyodide.org) 提供，網頁和指令版跑的是同一份 `m2w/`。第三方授權見 [THIRD_PARTY.md](THIRD_PARTY.md)。
